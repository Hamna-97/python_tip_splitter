# Python Tip Splitter

A beginner-friendly Python project that calculates the tip amount and splits the final bill equally among multiple people.

## Features
- Enter the total bill in PKR.
- Choose a tip percentage.
- Enter the number of people.
- Calculate the tip amount.
- Calculate the final bill.
- Split the bill equally.
- Basic input validation.

## Technologies Used
- Python 3
- Variables and Data Types
- User Input
- Conditional Statements
- Arithmetic Operations

## How to Run

1. Make sure Python 3 is installed.
2. Clone or download this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

```bash
bill and tip splitter.py
```

## Example

**Input:**
- Total bill: PKR 3000
- Tip percentage: 10%
- Number of people: 3

**Output:**
- Final bill: PKR 3300
- Each person pays: PKR 1100
